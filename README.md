# Hobart Equipment Repair source

This is a static website. There is no build step or package installation.

## Open it

1. Unzip the archive on your Mac.
2. Double-click `index.html` to preview it in a browser.
3. Open this folder in VS Code to explore and edit the code.

For a local web server, open Terminal in this folder and run `python3 -m http.server 8000`, then visit `http://localhost:8000`. Press Ctrl+C to stop it.

## How it works

- `index.html` contains the content and sections: header, hero, equipment cards, service approach, contact placeholder, footer.
- `styles.css` controls colors, typography, layout, hover states, and mobile breakpoints.
- `app.js` listens for equipment-card clicks and updates the service panel's heading and selection message.
- `assets/` contains optimized WebP product photos. `image-sources.json` records the original manufacturer pages. Public reuse rights for those photos have not been established.

The service section is intentionally a placeholder until the business name, location and contact details are supplied. This downloaded copy is independent of the private hosted draft; edits here will only change the copy on your Mac.
